# PERMIO (`apps/formulare`): aus dem Designsystem nachziehen

Offene Punkte aus der Designrichtlinie ([docs/design.md](../design.md)) für diese App. Neue Punkte trägt das
Designsystem ein. Erledigte Punkte löscht die App in ihrem eigenen PR (löschen, nicht abhaken). Dateiangaben beziehen
sich auf den Stand beim Eintragen.

- **Symbolknöpfe der Werkzeugleiste** (design.md „Zielgrößen“): Die globale Regel `button.icon { min-width: 24px; height: 24px; padding: 0 4px }` in `styles.css` hält „Mehr“ und Rückgängig in der Werkzeugleiste auf 24 px Breite (Höhe wird 28) – die Werkzeugleiste ausnehmen (`button.icon:not(.werkzeugleiste *)`); danach ist „Mehr“ dort 28×28 wie in den anderen Apps.
- **„Datei“ mit „Einstellungen …“ und „Exportieren“** (design.md „Kopf- und Werkzeugleisten“, „Einstellungen“): „Datei“ gibt es in jeder App; letzter Punkt hinter einem Trenner „Einstellungen …“ (`tasten: 'Strg+,'`, wirkt auch ohne offenes Menü) – er öffnet den zentralen Einstellungsdialog auf der Seite der App, sobald der Dialog im Designsystem (`packages/core`) bereitsteht. Ausgaben mit Dialog (Excel …, PDF …, CSV …) als Untermenü „Exportieren“ (Punkt mit `unter`) in „Datei“ statt als eigener Menüknopf. App-eigene Einstellungen ziehen auf die Seite der App im Dialog. Das eigene Layout `.es-*` (`styles.css`) wird zum gemeinsamen Muster `.einst*` in `base.css` – danach die App-Kopie streichen. „Einstellungen von PERMIO …“ im Menü „Mehr“ ist befristet: Er öffnet den bisherigen Dialog, bis dessen Inhalte als App-Seite im zentralen Dialog (`einstellungsSeiteAnmelden`, sobald der Baustein bereitsteht) stehen, dann entfällt er.
