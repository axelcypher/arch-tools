# RECTIO (`apps/entzerrung`): aus dem Designsystem nachziehen

Offene Punkte aus der Designrichtlinie ([docs/design.md](../design.md)) für diese App. Neue Punkte trägt das
Designsystem ein. Erledigte Punkte löscht die App in ihrem eigenen PR (löschen, nicht abhaken). Dateiangaben beziehen
sich auf den Stand beim Eintragen.

- **Marke aus core** (design.md „Skalen“, Marken): `.fw-marke` („entzerrt“ in `FotoWahl.tsx`, Regel in `styles.css`) ist eine Status-Marke. Sie wird `.marke info` oder `.marke ok` (kleine Rundung, `.pille` nur für Zuordnungen und Zähler), die eigene Regel entfällt.
