# QUADRIO (`apps/flaechenrechner`): aus dem Designsystem nachziehen

Offene Punkte aus der Designrichtlinie ([docs/design.md](../design.md)) für diese App. Neue Punkte trägt das
Designsystem ein. Erledigte Punkte löscht die App in ihrem eigenen PR (löschen, nicht abhaken). Dateiangaben beziehen
sich auf den Stand beim Eintragen.

- **Keine Programmnamen anderer Hersteller** (design.md „Begriffe“): `components/Toolbar.tsx` (title „Gebäudemodell aus Archicad, Revit & Co. importieren“ → „… aus dem CAD-Programm importieren“), `components/IfcImportDialog.tsx` („z. B. Archicad, Revit, Vectorworks“ streichen bzw. allgemein fassen), `components/Properties.tsx` („wie Archicad-Zonen“). Die Schritt-für-Schritt-Anleitung zum IFC-Export aus einem bestimmten Programm darf es nennen.
